# 小説プロジェクト

マルチメディア小説作品の制作リポジトリです。

## プロジェクト一覧

| プロジェクト | 説明 | ステータス |
|-------------|------|-----------|
| [都市幽霊草](projects/都市幽霊草/) | 深夜零時の遺失物係 - 現代ファンタジー連作短編 | 完結（全4話） |

## フォルダ構成

```
projects/
└── 都市幽霊草/          # 第1作品
    ├── 小説/            # 小説本文
    ├── data/            # キャラクター・シーン情報
    ├── prompts/         # 画像・音声生成プロンプト
    ├── images/          # 生成画像
    ├── assets/          # アセット素材
    └── scripts/         # 生成スクリプト
```

## 新しいプロジェクトの追加

`projects/` フォルダ内に新しいプロジェクトフォルダを作成してください。
