# 深夜零時の遺失物係（ロスト・アンド・ファウンド）

現代日本を舞台にした、失われた想いをめぐる連作短編小説。

## あらすじ

深夜零時を過ぎると、古びた駅舎の遺失物取扱所は「少し管轄が広がる」——。

消えかけた職員・灰谷レンと、想いを読み取る力を持つ新人・ユキが働くその窓口には、普通の落とし物だけでなく、人々が失くした「想い」が届けられる。

ある雨の夜、ずぶ濡れの女性・蒼井澄香が訪れる。彼女が探しているのは、10年前に失った「歌う声」。かつて歌手を目指し、挫折の末に自ら手放した夢の残滓は、怪異となってこの街に留まり続けていた。

失くしたものを取り戻すには——代償が、必要だ。

## 登場人物

### 灰谷レン
遺失物取扱所の職員。自身もまた「誰かの落とし物」であり、持ち主が迎えに来ないまま保管期限を過ぎ、消えかけている。『忘れないで』と刻まれた錆びた鍵を持ち、怪異を回収する力を持つ。回収のたびに自らの存在を代償として削る。

### ユキ
夜勤専門のアルバイト。物に残った「想い」を読み取る力がある。感情を表に出さない強さを持つが、大切な人を失った過去がある。

### 蒼井澄香
34歳の女性。10年前に歌手の夢を諦め、自らの「歌う声」を捨てた。父の形見のピックとともに置き去りにした声を取り戻すため、深夜の遺失物取扱所を訪れる。

## 世界観設定

### 怪異のルール
- 強い想いが物に宿ると「怪異」になる
- 「執着」から生まれた怪異は持ち主を求める
- 「拒絶」から生まれた怪異は持ち主を恨む
- 回収には代償が必要（時間、記憶、存在）

### 遺失物取扱所
- 深夜零時以降、普通の落とし物だけでなく「想い」も扱う
- 保管期限は三ヶ月
- 受け取るかどうかは持ち主の自由
