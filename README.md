# 深夜零時の遺失物係（ロスト・アンド・ファウンド）

現代日本を舞台にした、失われた想いをめぐる連作短編小説。

## あらすじ

深夜零時を過ぎると、古びた駅舎の遺失物取扱所は「少し管轄が広がる」——。

無気力な職員・灰谷レンと、感受性豊かな新人・ユキが働くその窓口には、普通の落とし物だけでなく、人々が失くした「想い」が届けられる。

ある雨の夜、ずぶ濡れの女性・蒼井澄香が訪れる。彼女が探しているのは、10年前に失った「歌う声」。かつて歌手を目指し、挫折の末に自ら手放した夢の残滓は、怪異となってこの街に留まり続けていた——。

## 登場人物

### 灰谷レン
遺失物取扱所の職員。無気力に見えるが、怪異化した「想い」を回収する能力を持つ。錆びた鍵を仕事道具として使う。

### ユキ
夜勤専門のアルバイト。物に残った「想い」を読み取る力があるが、すぐに感情移入して泣いてしまう。

### 蒼井澄香
34歳の女性。10年前に歌手の夢を諦め、自らの「歌う声」を捨てた。声を取り戻すため、深夜の遺失物取扱所を訪れる。
