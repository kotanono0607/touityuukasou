# ギャグパターン分析

## 参考：ウンチ・アツメウリ

### 分析したサンプル
1. カレー売りつけてくる隣人
2. いくら盛り放題
3. うんこマスター面接（フェルミ推定）

---

## 公式

```
真面目な体裁 × バカな概念 × 論理を貫く → 壊れる
```

---

## 共通パターン

| パターン | 例 |
|----------|-----|
| 同じ言葉を擦り続ける | 「無料」「よいしょ」「うんこマスター」 |
| 真面目な体裁 | 勧誘、寿司屋、就活面接 |
| 論理が壊れる | 体験だけ無料、負のいくら、全員マスター |
| 出題者・提案者がおかしい | 答え知らない、責任転嫁 |

---

## ツッコミのテクニック

- 相手の言葉を拾って返す
- 論理の矛盾を突く
- 比喩で殴る
- 鋭いフレーズで刺す

### 名ツッコミ例
- 「自分のミスを70億で割るな」
- 「フードロスを人質に取るな」
- 「事実を切り取って嘘にするな」
- 「哲学で殴るな」
- 「健康を人質に取るな」

---

## ボケのテクニック

- 普通のことを異常に強調
- 当然のように非常識なことを言う
- 被害者ぶる・逆ギレ
- 責任転嫁を堂々とやる

---

## 構造

1. 真面目な導入
2. 一つの概念を擦り始める
3. ツッコミが入る
4. 擦り続ける（エスカレート）
5. 論理が破綻
6. さらに壊れて終わる

---

## プロンプト用テンプレ

```
あなたはコメディ作家です。以下の条件で会話劇を書いてください。

■スタイル

- 論理が壊れても真面目に続ける

■ツッコミ
- 的確に刺す
- 比喩で殴る
- 鋭いフレーズ

■構造
- 真面目な導入 → 擦り始め → エスカレート → 破綻 → さらに壊す
```
