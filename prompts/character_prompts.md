# キャラクター画像生成プロンプト

本ファイルは『深夜零時の遺失物係』の主要キャラクター画像生成用プロンプトを収録。

**スタイル:** Light Novel Style（ラノベ表紙風・華やかで可愛い）

---

## 共通スタイル設定

### 必須タグ
```
light novel illustration style, soft shading, detailed beautiful eyes, character design sheet
```

### 品質タグ
```
high quality, detailed, masterpiece, best quality
```

### ネガティブプロンプト
```
realistic, photo, 3D, western cartoon, background, scenery, multiple people, bad anatomy, deformed, blurry, low quality, watermark, signature
```
